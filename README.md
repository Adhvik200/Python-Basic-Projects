## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Adhvik200/Python-Basic-Projects.git
```

Navigate into the project folder:

```bash
cd Python-Basic-Projects
```

Run any Python file:

```bash
python filename.py
```

Example:

```bash
python rockpaperscissors.py
```
